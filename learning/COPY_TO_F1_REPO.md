# Copy into f1-data-engineering

This Cloud Agent cannot push to the private `f1-data-engineering` repo. To make the plan live there:

```bash
cd ~/f1-data-engineering   # or Mac path
cp /path/to/Coursera/learning/LEARNING_PLAN.md ./LEARNING_PLAN.md
mkdir -p sql/drills
cp /path/to/Coursera/learning/sql-drills/README.md ./sql/drills/README.md
```

Then link it from `STATUS.md` under a “Learning plan” heading.
